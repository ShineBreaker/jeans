* 概述

GitHub Copilot 桌面应用 —— 基于 Tauri + WebKitGTK 的 agent-native 桌面客户端。

** 侧边 .so（运行时 dlopen）

- =native-plugins/libgithub_app_linux_pulse_plugin.so= → =libpulse*.so.0=（pulseaudio）
- =libonnxruntime.so= → C++ 运行时（libstdc++.so.6 等，gcc:lib 覆盖）

* 打包方案

参考 =reasonix-desktop-bin=（同为 Tauri/WebKitGTK 的 .deb 包）：

1. **不解压到 =opt/=，而是重构到 =libexec/github-copilot/=**
   - =github= 和 =git-credential-copilot= → =libexec/github-copilot/=
   - =usr/lib/GitHub Copilot/= 资源 → =libexec/github-copilot/resources/=

2. **ld-linux Wrapper（方案 B）**
   - 不 patchelf 巨型二进制（668 MB）
   - 用 Guix 的 =ld-linux= 启动，=--argv0= 保证 argv[0] 自定位
   - =--library-path= 扁平拼接所有 input 的 =/lib=
   - 额外把 =resources/= 加入 =LD_LIBRARY_PATH=，供 dlopen 加载 onnxruntime 等

3. **环境变量包装**
   =FONTCONFIG_FILE=, =XDG_DATA_DIRS=, =GI_TYPELIB_PATH=, =GIO_EXTRA_MODULES=, =GDK_PIXBUF_MODULE_FILE=

4. **两个 wrapper**
   - =bin/github= → 主应用
   - =bin/git-credential-copilot= → 凭据助手（也走 ld-linux，因为 NEEDED =libgcc_s=）

5. **.desktop + 图标**
   - 复制 =GitHub Copilot.desktop= → =github-copilot.desktop=
   - =Exec= 被 Guix 的 =patch-dot-desktop-files= 阶段自动改写为 store 路径
   - hicolor 图标原样复制

* 验证结果

- [X] =guix build= 成功
- [X] =guix lint= 仅剩标准噪声（=gcc:lib= 标签不匹配是整个通道的通用约定；SWH/updater 通知对专有 =-bin= 包不可避免）—— 比参考包 =reasonix-desktop-bin= 更干净（无 line-too-long）
- [X] =ld.so --list= 确认全部 23 个 NEEDED 库解析（0 个 not found）
- [X] =git-credential-copilot --help= 可执行（报 =COPILOT_TRAMPOLINE_PORT= 未设置属正常 —— 库已加载，应用逻辑在运行）
- [ ] 主 =github= GUI 完整启动测试 —— 无头环境无法进行，需在有显示的机器上 =guix shell github-copilot-bin -- github= 手动验证

* 更新器

URI =.../v<version>/...= 符合标准 =v= 前缀模式，无需在 =config.json= 的 =tag_prefix= 中特判。
CI 的 =auto-update.yml= 会自动跟踪 =github/app= 的新 release。

* 字体配置陷阱

=fontconfig-minimal= 的 name 是 =fontconfig-minimal=（非 =fontconfig=），但 build-side
用 =(this-package-input "fontconfig-minimal")= 可正确取到 store 路径，
因此 wrapper 中 =FONTCONFIG_FILE= 指向 =...-fontconfig-minimal-2.16.0/etc/fonts/fonts.conf=。
